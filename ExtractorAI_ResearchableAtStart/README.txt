Extractor AI Researchable at Start
==================================
สำหรับ Surviving Mars: Relaunched

ทำอะไร
- เผย Breakthrough "Extractor AI" ให้วิจัยได้ตั้งแต่ต้นเกม
- ไม่ได้วิจัยให้ฟรี ยังต้องจ่าย Tech Point / กดวิจัยเอง
- หลังวิจัยแล้ว เครื่องขุด Metals / Rare Metals ทำงานไร้คนที่ 50% ได้ (ปิดช่องแรงงานเป็นสีแดงตามของแท้)

ติดตั้ง
1. Download ZIP จาก GitHub แล้วแตกออก
2. วางโฟลเดอร์ชื่อ ExtractorAI_ResearchableAtStart ลงใน Mods ของเกม เช่น
   %AppData%\Surviving Mars Relaunched\Mods
   หรือ
   %AppData%\Surviving Mars\Mods
   (ถ้ายังไม่มีโฟลเดอร์ Mods ให้สร้างเอง)
3. เปิดเกม → Mod Manager → เปิดม็อดนี้
4. เริ่มเกมใหม่ (แนะนำ) หรือโหลดเซฟเก่าก็ใช้ได้

วิธีเช็คว่าติด
- เปิดหน้า Research แล้วหา Extractor AI ใน Breakthroughs
- ยังต้องวิจัยก่อน extractor จะวิ่งอัตโนมัติ

หมายเหตุ
- ถ้า Extractor AI จะขึ้นจาก anomaly ในแมพนี้ ม็อดจะดึงออกจากคิวสุ่ม เพื่อไม่ให้ซ้ำ
- ไม่แตะอาคาร ไม่แตะสูตรผลิต
